# 📖 ENG 与 EMG 算法的故事

想象一下，你的身体里有两种"电线"——**神经**和**肌肉**。它们的工作方式就像城市里的电话线和电网，各自传递不同的"信息"和"能量"。

---

## 🧠 第一个主角：ENG 噪声侦探 (Noise Detector)

**场景**：一个安静的神经科学实验室

在一条细细的神经纤维上，科学家放置了一对微小的电极，就像在电话线上安装了一个窃听器。他们想听到的是神经传递的微弱信号——那些只有 **5-10 微伏** 的"悄悄话"（比你头皮上的脑电波还要小100倍！）。

**问题来了**：
- 实验者的手不小心动了一下 → 电极晃动，产生**运动噪声**
- 旁边有其他设备在工作 → 产生**电磁干扰**
- 患者的皮肤出汗了 → **电极接触变差**

这些"噪音"就像是电话里的杂音，把真正的神经信号淹没了。

### ENG 噪声侦探的任务
> "告诉我，这段信号里的每一毫秒，是真正的神经活动，还是噪音干扰？"

它的工具是一个叫 **1D U-Net** 的深度学习模型，就像一个超级敏锐的听觉系统：
- **输入**：一段 ENG 信号（双通道：原始信号 + 变化速度）
- **工作原理**：先"压缩"信号找到噪声的模式，再"还原"回去标记每个时间点
- **输出**：一个"0 或 1"的地图——0 表示"干净"，1 表示"这里有噪声！"

---

## 💪 第二个主角：EMG 手势翻译官 (Gesture Classifier)

**场景**：一个未来的假肢研究中心

一位失去前臂的患者，戴上了一个布满 **16 个电极** 的手环。每当他"想象"自己在做某个手势——比如握拳、捏东西、或者用手指指向远方——他前臂残存的肌肉就会产生微弱的电信号。

**问题来了**：
- 16 个电极，每秒 2048 个数据点，信息量太大了！
- 不同人的手臂粗细、肌肉分布都不同
- 同一个手势，每次做的时候信号都略有不同

### EMG 手势翻译官的任务
> "根据这些肌肉电信号，告诉我他正在做 16 种手势中的哪一种？"

它的工具是一个 **1D CNN 分类器**，就像一个训练有素的读心术大师：
- **输入**：32 通道信号（16 个原始 EMG + 16 个变化速度）
- **工作原理**：通过层层卷积，提取肌肉激活的"指纹"
- **输出**：16 个分数——哪个手势的分数最高，就是答案

---

## 🎯 它们的共同目标

| | ENG 噪声侦探 | EMG 手势翻译官 |
|---|---|---|
| **信号来源** | 神经 | 肌肉 |
| **任务类型** | 分割 (每个点打标签) | 分类 (整段信号归类) |
| **应用场景** | 神经电生理研究、脑机接口 | 假肢控制、手势识别 |
| **核心技术** | U-Net | CNN |
| **"双通道"升级** | 原始信号 + 变化率 | 16 通道 × 2 = 32 通道 |
